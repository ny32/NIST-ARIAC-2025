# Run Instructions

Instructions for running the ARIAC simulation locally.

## Prerequisites

- **Python 3.12.4** or later (recommended: 3.12.4)

Verify your Python installation:

```bash
python --version
```

## Quick Start

1. **Install Dependencies**

   ```bash
   pip install -r requirements.txt
   ```

2. **Run the Simulation**

   ```bash
   cd ariacmaster/ariacmaster/task1
   python main.py
   ```

## Configuration

### Edit Simulation Constants

Modify the constants to customize the simulation behavior:

**Using VS Code:**

```bash
code core/constants.py
```

**Using System Default:**

```bash
start core/constants.py
```

The constants file is located at: `ariacmaster/ariacmaster/task1/core/constants.py`
